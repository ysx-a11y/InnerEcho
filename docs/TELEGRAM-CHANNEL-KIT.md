# 镜界自白 Telegram 引流频道运营包

> 定位：TG 只做**单向引流**——频道发内容、带链接回网站，不建群、不投稿、不互动。
> 内容库已预制 24 篇（`scripts/telegram-posts.json`），由 `innerecho-tgchannel` 进程按间隔自动发布，循环使用。

## 1. 建频道（一次性，约 5 分钟）

1. 私聊 `@BotFather` → `/newbot` → 填名字（如 `镜界自白发布`）→ 填用户名（需以 bot 结尾，如 `jingjie_zibai_bot`）→ 拿到 token。
2. Telegram 新建频道，选**公开频道**（公开才有 @用户名，互推和导航站都要它）。
3. 频道设置 → 管理员 → 把刚建的 bot 加为管理员，**只勾「发布消息」**，其余权限全关。
4. 把 bot token 和频道 @用户名 交给部署方保管（凭据不入仓库）。

## 2. 发布节奏与内容维护

- 默认每 **12 小时**自动发一篇（`TG_POST_INTERVAL_HOURS` 可调），24 篇循环使用。
