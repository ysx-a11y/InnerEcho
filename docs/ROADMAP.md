# 《镜界自白（InnerEcho）》产品演进路线图

本文档记录当前产品判断。优先级以“用户是否愿意完成一次自白、是否感到被理解、是否愿意再次回来”为核心，不以功能数量为目标。

## 1. 当前优先落地

### P1：LLM 解读质量基线

- 使用完全合成、不含真实用户信息的样本建立可重复评测。
- 重点检查内容是否扎根具体回答、是否出现模板套话、无依据诊断、性别推断、跨题库串词或监视感表达。
- 同一合成样本重复生成，观察称号、核心判断和建议是否保持合理稳定。
- 每次调整提示词或模型后先运行质量评测，再决定是否上线。
- LLM 请求使用 DeepSeek JSON Output 模式，结构化格式失败不再依赖提示词碰运气。

### P2：树洞式信任体验

- 保持页面语气与树洞式体验一致，不突然切换成法律告知或后台审计口吻。
- 研究可选的“隐身模式”：页面失焦模糊、快速离开、会话结束清理本地草稿等；默认不制造紧张感。
- 明确区分产品确实能做到的保护与网页无法保证的能力，不宣称可以阻止系统截图或浏览器历史记录。

### P3：任务功能采用弱连接实验

- 不根据停顿、退格、触摸等遥测自动推送任务。
- 报告结束后仅提供一次低压力邀请，例如“想把这次发现变成一个小尝试吗？”
- 推荐只使用报告中的高层主题标签，不引用用户私密原话。
- 用户可以选择“暂时不要”“换一个”或“这不像我”；不形成服从度、完成率等人格判断。
- 先通过小范围反馈确认不产生冒犯或监视感，再决定是否加深联动。

## 2. 暂缓事项

### 数据页

- 当前真实数据量不足，图表和趋势容易显得空洞，也可能制造并不存在的统计意义。
- 等积累足够且具有时间跨度的数据后，再决定展示历史变化、群体匿名分布或个人复测趋势。
- 暂缓期间不为填满页面而生成伪趋势或过度解释两个样本。

### 动态心跳与海报主题扩展

- 心跳反馈、暗夜极光、极夜金箔、禁忌羊皮纸、赛博青冰等视觉方案保留。
- 等核心解读质量和主要流程稳定后再做，避免视觉精致度掩盖内容重复或结果不可信。

## 3. 中期探索

### 双人／灵魂伴侣反差契合度测试

- 等有第一批真实使用反馈后再验证需求。
- 必须由双方分别主动加入；邀请方不能看到对方原始回答。
- 输出聚焦双方愿意共享的主题与边界，不生成单方面的“读心报告”。

### 1v1“暗面双生”AI 对话

- 先验证单次卷宗的质量、边界和成本，再考虑连续对话。
- 对话引用历史自白必须由用户当次明确选择，不能默认加载全部私密数据。

## 4. 外部条件具备后处理

- 配置线上错误监控和告警。
- 演练数据库备份恢复与字段加密密钥轮换。
- 在真实部署环境执行迁移、登录、生成卷宗和任务领取冒烟测试。

这些工作涉及生产服务器或另一台设备上的密钥，当前只保留方案，不在本地冒充已完成。
