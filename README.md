# 镜界自白（InnerEcho）

> 🔮 **反差自白、潜意识倾诉与私密属性诊断应用**

## 📖 项目简介

镜界自白（InnerEcho）是一款面向反差自白、潜意识心理与私密倾向的互动问答与属性诊断应用。通过表里反差设定、多路径主题探索、剧情沉浸叙事与反差深度测评（轻度/中度/深度），为用户呈现专属的隐私保护声明、成就徽章与一键保存的高清匿名诊断报告海报。
